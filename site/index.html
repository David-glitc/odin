The work, in the order you want to read it.

Odin leads with the goal and a short summary in plain text. Every claim has a footnote that opens the task it came from.

Goal

Your request in one plain line. The page starts here, so you never lose the point of the work.

Plan and progress

Each step, done or pending, with a bar. Replay ticks the steps off in the order they happened.

Findings

What the agent found, in order. The recap it wrote at the end of each task, not a log of every call.

Decisions

Every question the agent asked, the options, and the answer you gave. Nothing gets asked twice.

Changes

Files with edit counts, commits, deploys and links. Files written by shell commands count too.

Needs you

What waits on you, with its options. Only the newest task can wait, so the list stays honest.

Not the harness.

Ask Claude Code: show me what you are doing. Or build a page by hand from any session.

Open the page. Start with the summary, follow a footnote, answer what waits on you.

Runs on your machine. Python 3 only. Output is redacted by pattern (tokens, keys, long hex, seed phrases), and you should still read a page before you share it. Summaries follow ASD-STE100 Simplified Technical English rules.
